# Gordinho Celulares - Landing Page de Alta Conversão

Landing Page ultra moderna, dinâmica, mobile-first e de alta conversão (CRO), voltada para campanhas de tráfego pago (Meta Ads e Google Ads) promovendo a venda de smartphones **Xiaomi** e **Realme** parcelados no **Boleto Bancário** em até 24x sem depender de limite no cartão de crédito.

## 🚀 Tecnologias Utilizadas
- **HTML5 Semântico:** Estrutura acessível, otimizada para SEO e Open Graph para compartilhamento social.
- **CSS3 Moderno:** Design System com suporte a **Tema Escuro (Dark Mode)** e **Tema Claro (Light Mode)**, Glassmorphism, Microinterações aceleradas por GPU.
- **JavaScript Puro (Vanilla JS):** Validação de campos em tempo real, máscara inteligente de WhatsApp (com suporte a DDI), acordeão dinâmico e integração direta com o WhatsApp oficial da loja.

## ✨ Recursos de Destaque
- **Alternância de Tema (Claro / Escuro):** Botão no cabeçalho com persistência em `localStorage`.
- **Vitrine Interativa de Aparelhos:** Cards com iluminação de estúdio para os modelos Xiaomi Redmi Note 15, Xiaomi Poco C81 Pro, Realme C85 Ultra e Realme P4 Power 5G.
- **Integração WhatsApp Anti-Popup Blocker:** Disparo síncrono com dados pré-formatados direto para o WhatsApp oficial: `(67) 99245-1418`.
- **Prova Social e Autoridade Local:** Mais de 15 anos de tradição em Campo Grande – MS (Av. Noroeste, 5338, Centro).

## 💻 Como Visualizar Localmente
Basta abrir o arquivo `index.html` em qualquer navegador ou executar:
```bash
python -m http.server 8080
```
E acessar `http://localhost:8080`.
